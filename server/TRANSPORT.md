# Захищений транспорт сервера HromadaAID

Конфігурація `configVersion: 1` з етапу 8.2.1 продовжує працювати як локальний HTTP-сервер на loopback. Для нових конфігурацій використовуйте `configVersion: 2` та `mode` зі значенням `local` або `network`.

У режимі `local` сервер слухає лише `127.0.0.1`, `::1` або `localhost` через HTTP. У режимі `network` поле `host` має містити конкретну нелокальну IPv4/IPv6 адресу інтерфейсу. Wildcard-адреси заборонені. Сервер вимагає доступні PEM-файли сертифіката й приватного ключа; за потреби `certificateChainPath` вказує на PEM-файл із проміжними сертифікатами. Сертифікат і ключ перевіряються до створення Fastify, а мінімальна версія TLS – 1.2. Приклади конфігурацій: `installed-config.example.json` та `installed-config.network.example.json`.

Електронний клієнт перевіряє ланцюг довіри та ім'я сервера стандартною перевіркою Node.js TLS. Ім'я в сертифікаті Subject Alternative Name має відповідати саме імені, яке користувач вводить в адресу сервера. Для Tailscale використовуйте DNS-ім'я або адресу, включену до сертифіката. Клієнт відхиляє недовірені, прострочені та невідповідні сертифікати; самопідписаний сертифікат потребує довіри через звичайний механізм довіреної CA до підключення. Не вимикайте TLS-перевірку. Tailscale не замінює автентифікацію HromadaAID.

Перенаправлення HTTP-запитів клієнта заборонені, зокрема HTTPS-перенаправлення на HTTP. Приватний ключ не вбудовується в клієнтську конфігурацію чи звіти. До інтеграції інсталятора забезпечте читання файла ключа лише обліковим записом серверної служби; встановлення сертифікатів до сховища Windows автоматично не виконується.

Для приватного центру сертифікації безпечний варіант – додати його CA до стандартного Node.js trust set через `NODE_EXTRA_CA_CERTS`, заданий процесу Electron до його запуску. Це розширює перелік довірених CA, але залишає перевірку ланцюга, строку дії та імені сервера. Інсталятор може налаштувати цей механізм окремо; інтерфейсу прийняття довільного сертифіката немає. Змінна читається під час запуску Node.js, тому її не можна встановити постфактум із renderer.
