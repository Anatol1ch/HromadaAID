# Пакети HromadaAID Deployment 2.0

Команда `pnpm windows:deployment-packages` формує два незалежні каталоги в `release/deployment-v2/Пакети HromadaAID`:

- `Client` — розпакований Windows payload Electron Builder. Його можна використати для стандартного подальшого встановлення через electron-builder.
- `Server` — Fastify-застосунок, комплектний Node.js, фізичне production-дерево залежностей, WinSW та службові скрипти.

Ця команда не запускає інсталятор і не реєструє Windows Service. Вона повторно використовує чинний крок формування серверного payload, а потім створює окремі Deployment 2.0 пакети.

## Маніфести

Кожен пакет має `package-manifest.json` з `formatVersion`, `packageSchemaVersion`, назвою компонента, версією, `win32`/`x64`, сумісністю та SHA-256 кожного payload-файла. Перевірка звіряє фактичний перелік файлів, розмір і хеші; серверний пакет додатково проходить перевірку цілісності та runtime smoke test із комплектним Node.js.

Хеші виявляють пошкодження, але не доводять походження пакета. Маніфест Deployment 2.0 не додає перевірки цифрового підпису; чинна політика поширення описана в [docs/DECISIONS.md](../docs/DECISIONS.md).

## Сумісність

До Deployment 2.0 API не мав формальної версії. Введено контракт `hromadaaid-rest` v1, що фіксується у відповіді `/health` полем `apiContractVersion`. Клієнт v1 приймає відповіді без цього поля як попередню, сумісну форму v1; невідому явну версію відхиляє. Клієнтський маніфест декларує підтримку API v1. Майбутня несумісна зміна REST-контракту повинна збільшити версію та оновити діапазони сумісності.

Серверний маніфест містить фактичний максимум схеми SQLite, отриманий від `create-admin.js --status` із комплектним Node.js; наразі підтримуваний діапазон — 1–28. Під час оновлення цей діапазон призначений для перевірки сумісності, він не запускає та не відкочує міграції самостійно.

## Вміст клієнта

Клієнтський пакет походить із `release/win-unpacked`; він не містить окремого `node.exe`, WinSW або серверного payload. Вміст `resources/app.asar` також перевіряється на серверні виконувані файли, серверні модулі, SQLite/секретні файли та скомпільовані тестові файли.
