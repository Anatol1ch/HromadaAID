# HromadaAID v1.0.1

Підготовлено локально. Реліз ще не опублікований.

## Платіжні документи

- Персональні та зведені списки формуються окремо для кожної комбінації виду
  матеріальної допомоги й банку. Персональні списки автоматично діляться
  на частини до 12 призначень.
- Банківські відомості створюються окремими файлами за банками. Різні види допомоги
  одного банку включаються разом.
- У параметрах можна вибрати один, кілька або всі банки позначених призначень.
  Кількість призначень, документів і загальна сума оновлюються одразу.
- Компактне модальне вікно має плашки вибору банків, картки реквізитів і доступні
  під час прокручування кнопки дій. Введені параметри зберігаються при згортанні.
- У таблиці «Формування відомостей» додано стовпець «Банк» між видом допомоги
  та статусом. Для відсутнього банку показується «Не вказано».
- Покращено перевірку актуальних даних перед формуванням, реквізитів,
  складу груп, сум і повторних назв файлів. Помилка одного файла скасовує
  весь поточний пакет.

Кожне призначення залишається окремим записом. Кількість у зведеному списку —
це кількість призначень, а не унікальних отримувачів. Генерація документів
не змінює статусів, сум, дат фактичних виплат чи фінансових зв'язків.
Дати та періоди документа зберігають попередню семантику.

## Адреси Server Manager

- Автоматичне визначення мережевих адрес замінено ручним введенням
  Loopback, LAN і Tailscale.
- Адреси редагуються у компактному вікні та копіюються кнопкою біля значення.
  Початковий Loopback — http://127.0.0.1:4310; LAN/Tailscale можна очистити.
- Налаштування зберігаються між запусками й стандартними оновленнями
  в профілі того самого Windows-користувача.
- Збереження перевіряє формат, не вимагає доступного сервера та захищає
  пошкоджений або несумісний файл від автоматичного перезапису.

Ручні адреси не змінюють IP Windows, Tailscale, server.json, listener
або підключення Client. Незалежна діагностика служби та локального API збережена.

## Відомі обмеження

- Для формування документів потрібен Microsoft Excel через Windows COM.
- Excel-шаблони незмінені. Сумісність формату банківського файла на основі
  «ПриватБанк.xlsx» з імпортом інших банків не підтверджена.
- Некоректне сховище адрес Manager блокує редагування до усунення причини;
  автоматичного reset немає.

## Очікуваний комплект Windows x64

Після окремо погодженої публікації очікуються:

- HromadaAID-Setup-1.0.1.exe — Universal Setup для Client, Server або повного комплекту.
- HromadaAID-Server-v1.0.1-win-x64.zip — пакет оновлення API Server через Manager.
- release-manifest.json — метадані версії, сумісності та цілісності файлів.

Ці файли ще не опубліковані. Механізми встановлення, оновлення, авторизації
й резервного копіювання залишаються чинними.
