# HromadaAID v1.0.0

Перший Production Release настільної системи обліку матеріальних допомог громади з українським інтерфейсом.

- Client працює через API Server із централізованою SQLite; Server Manager забезпечує адміністрування. Universal Setup підтримує Client-only, Server-only і Combined.
- Облік рішень виконкому, призначень, статусів та фактичних виплат; робочі облікові роки.
- Реєстри отримувачів і банків із наборами банківських реквізитів.
- Формування персональних, зведених і банківських платіжних документів через наявні Excel-шаблони та Windows Excel COM.
- Річне планування та звітність за періодами, суми призначень і виплат.
- Облікові записи, ролі та розмежування доступу.
- Серверне резервне копіювання та контрольоване відновлення через Server Manager.
- Stable-оновлення Client/Manager через Universal Setup та API Server через ZIP-пакет у Manager відповідної версії.
- Автоматична блокувальна перевірка МФО (6 цифр) і ЄДРПОУ (8 цифр) на клієнті й сервері. Початкові нулі зберігаються; контрольний розряд ЄДРПОУ не перевіряється.
- Кнопка «Перевірити IBAN» перевіряє український формат і MOD 97 без нових блокувальних правил збереження. Існування та належність рахунку не перевіряються.

Stage 9.5 функціонально прийнято власником у dev-збірці. Оновлення з 0.2.2 використовує чинні механізми; Manager оновлюється перед API Server.

Комплект Windows x64:
- HromadaAID-Setup-1.0.0.exe
- HromadaAID-Server-v1.0.0-win-x64.zip
- release-manifest.json

Для Excel-генерації потрібен Microsoft Excel у Windows. Відоме інформаційне обмеження: Manager може некоректно показувати LAN/Tailscale IPv4 у деяких Windows VM; адресу Client можна ввести вручну. Tailscale налаштовується окремо. Внутрішній LAN HTTP не шифрується.
