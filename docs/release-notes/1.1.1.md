# HromadaAID Stable 1.1.1

У новій версії HromadaAID особливу увагу приділено стабільності роботи системи, надійності оновлення програмних компонентів та зручності користування застосунком. Повністю оновлено розділ налаштувань, додано історію версій програми та вдосконалено інструменти адміністрування сервера.

## Оновлений розділ налаштувань

Повністю перероблено інтерфейс налаштувань HromadaAID. Інформацію та функції розподілено між п’ятьма тематичними розділами:

- Загальні – керування масштабом інтерфейсу та режимом бічного меню.
- Обліковий запис – інформація про користувача, його ролі та зміна пароля.
- Підключення – інформація про сервер, стан з’єднання та засоби діагностики.
- Оновлення – перевірка наявності нових версій та перегляд історії оновлень.
- Про програму – загальна інформація про HromadaAID.

Додано можливість змінювати масштаб інтерфейсу безпосередньо в налаштуваннях. Вибраний масштаб зберігається після закриття програми.

Покращено загальне оформлення, навігацію, читабельність інформації та зручність роботи з параметрами застосунку.

## Історія оновлень

Додано можливість переглядати історію версій HromadaAID безпосередньо в програмі.

- Доступний перелік опублікованих стабільних версій із датами їх випуску.
- Для кожної версії можна переглянути повний опис нових можливостей, вдосконалень та виправлень.
- Поточна встановлена версія позначається окремо.
- Раніше доступні описи оновлень можна переглядати навіть за відсутності підключення до Інтернету.

Історія оновлень доступна в розділі «Налаштування» → «Оновлення».

## Надійність оновлення програми

- Виправлено проблему, через яку вікно оновлення могло бути недоступним за відсутності з’єднання із сервером.
- Перевірка наявності оновлень доступна навіть за відсутності з’єднання із сервером. Якщо нова версія програми потребує оновлення серверної частини, її встановлення відкладається до підтвердження готовності сервера.
- Вдосконалено координацію оновлень клієнтських і серверних компонентів для запобігання встановленню несумісних версій.
- Покращено відображення стану перевірки оновлень та повідомлень про її результати.

## Підключення до сервера

- Відтепер програма розрізняє відсутність з’єднання із сервером та несумісність версій програмних компонентів.
- Оновлено оформлення системних екранів і повідомлень про проблеми підключення.
- Додано можливість перевірити наявність оновлень безпосередньо з екрана втрати з’єднання.
- У налаштуваннях додано засоби діагностики підключення та копіювання технічної інформації для адміністратора.

## Вдосконалення Server Manager

- Покращено діагностику проблем, пов’язаних із серверними оновленнями.
- Додано детальну інформацію про залишкові службові каталоги та можливість копіювання діагностичних відомостей.
- Реалізовано безпечне архівування залишкових файлів оновлення з попередньою перевіркою стану сервера та підтвердженням адміністратора.
- Виправлено причини появи окремих залишкових каталогів після скасування оновлення.
- Вдосконалено обробку помилок завершального очищення службових файлів.

Архівування залишкових файлів не передбачає видалення робочої бази даних, конфігурації або активного серверного пакета.

## Важлива інформація щодо оновлення

Версія 1.1.1 зберігає сумісність із серверними та клієнтськими компонентами версії 1.1.0.

Для отримання всіх вдосконалень рекомендується оновити компоненти в такому порядку:

1. HromadaAID Server Manager.
2. API Server.
3. Клієнтські застосунки HromadaAID.

Перед оновленням серверної частини рекомендується створити резервну копію бази даних.

Якщо після попереднього оновлення Server Manager відображає попередження про залишкові файли, скористайтеся новим інструментом їх усунення після оновлення Server Manager до версії 1.1.1. Не видаляйте службові каталоги вручну.
