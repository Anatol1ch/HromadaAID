# HromadaAID v1.0.2

Підготовлено локально; реліз ще не опублікований.

## Виправлення

- Персональні списки показують суми з розділенням тисяч і двома десятковими
  знаками, наприклад `1 000,00` та `1 234,50`. Значення лишаються числовими
  клітинками Excel; підсумкова формула збережена.
- В останню колонку персонального списку передається адреса проживання з картки
  отримувача. Підтримуються структурована адреса та старе текстове поле.
  Якщо адреси проживання немає, формування зупиняється з повідомленням про
  необхідність заповнити картку; адресу реєстрації автоматично не підставлено.
- Відповідь старого або несумісного API Server без поля адреси проживання тепер
  відрізняється від порожньої адреси й повідомляє про необхідність перевірити
  версію сервера.

Зведені та банківські документи, правила групування, фінансовий облік і шаблони
не змінені. Міграцій SQLite немає.

## Відоме обмеження

Заголовок останньої колонки у незміненому шаблоні `Список.xlsx` досі має текст
«Адреса реєстрації», хоча в колонку передається адреса проживання. Коригування
заголовка шаблону потребує окремого рішення.

## Планований склад Windows x64

- `HromadaAID-Setup-1.0.2.exe`
- `HromadaAID-Server-v1.0.2-win-x64.zip`
- `release-manifest.json`

Файли цього релізу ще не створювалися та не опубліковані.
