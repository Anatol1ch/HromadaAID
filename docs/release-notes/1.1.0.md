# HromadaAID Stable 1.1.0

У новій версії HromadaAID вдосконалено роботу з реєстром матеріальної допомоги, оновлено картку отримувача, покращено інтерфейс та навігацію, а також посилено контроль коректності даних і виконання операцій.

## Важлива інформація щодо оновлення

Ця версія містить зміни у взаємодії клієнтських і серверних компонентів. Для коректної роботи системи необхідно оновити всі компоненти HromadaAID до версії 1.1.0.

Рекомендований порядок оновлення:

1. Створіть резервну копію бази даних.
2. Завершіть роботу всіх клієнтських застосунків.
3. Оновіть HromadaAID Server Manager.
4. Через оновлений Server Manager виконайте оновлення API Server.
5. Оновіть клієнтські застосунки HromadaAID на всіх робочих місцях.
6. Перевірте доступність сервера та підключення клієнтських застосунків.

Одночасне використання клієнтських і серверних компонентів версій 1.0.2 та 1.1.0 не підтримується.

## Робота з матеріальною допомогою

- Розширено повноваження фахівців з призначень. Тепер вони можуть видаляти призначення зі статусами «Призначено», «В роботі» та «Передано до казначейства», якщо за ними раніше не здійснювалися виплати.
- Збережено захист від видалення фахівцями виплачених призначень та призначень з історією виплат, зокрема відкликаних.
- Вдосконалено панель масової зміни статусів. Інструменти роботи з вибраними записами тепер зручно розташовані над таблицею.
- Покращено фільтрацію та оформлення реєстру матеріальної допомоги.
- Оновлено підсумковий рядок реєстру. Загальна кількість записів та їх сума тепер розраховуються за всіма призначеннями, що відповідають поточному пошуку та вибраним фільтрам, незалежно від їхнього статусу.

## Оновлена картка отримувача

- Перероблено інтерфейс створення та редагування карток отримувачів.
- Інформацію згруповано у чотири розділи: особисті дані, адреси, контактні дані та банківські реквізити.
- Покращено оформлення адресних блоків, додавання, редагування та очищення адрес.
- Реалізовано зручне копіювання адреси реєстрації в адресу проживання та навпаки.
- Адреса реєстрації та адреса проживання тепер є обов’язковими для збереження картки отримувача.
- Спрощено введення номера телефону та номера банківського рахунка завдяки окремому відображенню префіксів +380 та UA.
- Покращено читабельність номера банківського рахунка та відображення МФО і ЄДРПОУ банку.
- Вдосконалено оформлення перевірки IBAN. Користувач може перевірити правильність формату та контрольної суми введеного номера рахунка.
- Додано інформаційні підказки та пояснення щодо заповнення окремих полів.

Правила формування персональних списків виплат залишилися незмінними: для них використовується адреса проживання отримувача.

## Інтерфейс та зручність роботи

- Оновлено бічне меню навігації та його компактний режим.
- Вдосконалено верхню панель програми, навігаційні елементи та вибір облікового року.
- Покращено використання доступної площі екрана. Робочі області адаптуються до ширини вікна програми.
- Вдосконалено оформлення таблиць, фільтрів, кнопок та діалогових вікон.
- Покращено відображення недоступних функцій і повідомлень про обмеження прав доступу.
- Спрощено оформлення вікна застосунку зі збереженням можливості зміни масштабу інтерфейсу.

## Стабільність та захист даних

- Посилено серверний контроль прав доступу під час видалення призначень матеріальної допомоги.
- Вдосконалено перевірку обов’язкових даних отримувачів.
- Оновлено механізм перевірки сумісності клієнтських і серверних компонентів.
- Усунено низку функціональних та візуальних недоліків, що впливали на зручність повсякденної роботи із системою.
